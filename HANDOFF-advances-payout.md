## Що зроблено

- **Групи виплат «як у таблиці залічок»**: затвердження 1–14 → виплата 15-го, 15–29 → 30-го,
  30–31 → 15-го наступного місяця (`api-server/src/lib/advancePayout.ts`, під тестами).
  Ставиться і з веба, і з бот-кнопки затвердження; перенесення вручну — `PATCH /advances/:id`
  (кнопка ⇄ на сторінці). Поля: `advance_requests.payout_month/payout_group`.
- **Офісна подача** `POST /advances`: одразу статус `approved` (в UI — «Передано до виплати»)
  від імені подавача; `decided_by` = «хто подав або підтвердив» (окремої колонки нема — для
  бот-запитів це той, хто затвердив). Працівнику летить сповіщення його мовою.
- **Метод виплати** `advance_requests.paid_method` (`transfer|cash`): ручна помітка «Виплачено»
  вимагає вибору в модалці (дата виплати = день кліку); банківський авто-матч
  (`services/advances.ts`) пише `transfer`.
- **Номер рахунку працівника**: `worker_bank_accounts.is_primary` (unique partial index на
  worker_id). Перший ручний рахунок стає основним автоматично; перемикання — у профілі
  (картка «Банківські рахунки»), `POST /worker-bank-accounts/:id/primary`. На сторінці
  авансів IBAN під іменем (основний → найновіший ручний → авто), клік = копіювання.
- **Веб** (`web/src/pages/Advances.tsx` переписана): місяць → група «Виплата 15-го/30-го» →
  місто → фірма (company працівника) → фабрика, підсумки на кожному рівні; фільтр статусів;
  модалки подачі/виплати/перенесення/відхилення; i18n uk/en.
- **Бот**: статус approved у текстах = «передано до виплати» (5 мов, `notif.advApproved`,
  `adv.stApproved`).
- **Фікс SPA-фолбека** (`app.ts`): `res.sendFile("index.html", { root: webDist })` — без root
  пакет `send` перевіряє на dot-сегменти весь абсолютний шлях і 404-ить збірку, запущену
  з git-worktree під `.claude/worktrees/` (на проді не проявлялося).

Тести: 349/349 (юніти + інтеграційні), нові — `lib/advancePayout.test.ts`,
розширений `routes/advances.integration.test.ts`.
