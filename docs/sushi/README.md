# 🍣 Специфікація модуля «Суші» (Sushi & Food Factory)

Головний навігаційний документ архітектури, вимог та плану перенесення/розвитку функціоналу фабрики «Суші» в основну систему **Grafik-bot**.

---

## 📑 Зміст та модулі системи

| Модуль | Документ | Опис |
| :--- | :--- | :--- |
| **01. Облік та обробка годин** | [`01-hours-accounting.md`](./01-hours-accounting.md) | Відмова від Google Sheets/Excel. Правила розрахунку часу, 15-хв округлення, невалідні записи, деревоподібна картка працівника (Рік → Місяць → День → Інтервали). |
| **02. Підтвердження та диспути** | [`02-disputes-confirmations.md`](./02-disputes-confirmations.md) | Флоу підтвердження змін робітником, подача скарг (диспутів), кабінет координатора, Telegram/Web сповіщення. |
| **03. Ролі, лінії та графіки** | [`03-roles-lines-schedules.md`](./03-roles-lines-schedules.md) | Довідник локальних ролей (лідер, бригадир, скочек, учень), довідник виробничих ліній, адаптований генератор і Drag-and-Drop редактор графіків. |
| **04. Аутсорсинг та фінанси (P&L)** | [`04-outsourcing-finance-pnl.md`](./04-outsourcing-finance-pnl.md) | Двоконтурна система годин (фабрика vs працівник), списання різниці за помилки з бригадирів, ієрархія ставок (override), оплата за робочий одяг (6 zł). |

## 🏛 Архітектурні принципи та правила проєкту

1. **Безпека кодової бази:** Жодного написання чи редагування коду без прямої команди користувача.
2. **Дослідження:** Усі пошуки по системі проводяться через ізольованих дослідницьких субагентів із фіксацією точних посилань на файли та номери рядків.
3. **Єдина PostgreSQL БД:** Відмова від локального SQLite (`sushi_bot_local.db`). Усі сутності інтегруються в центральну базу даних `lib/db/src/schema/workers.ts`.
4. **CSRF & Безпека API:** Будь-які веб-мутації проходять через захищений клієнт з заголовком `X-Requested-With: grafik`.
5. **Багатомовність (i18n):** Веб-панель (UK/EN), бот (5 мов для працівників, UK/EN для координаторів).
