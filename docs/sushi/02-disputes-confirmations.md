# 🤝 Модуль 02: Підтвердження змін та робота зі скаргами (Disputes)

---

## 1. Користувацький флоу працівника (Worker Flow)

1. **Перегляд відпрацьованих годин:**
   - Працівник у Telegram-боті або в особистому кабінеті переглядає підсумок за місяць та розбивку по днях.
   - Бачить деталізовані інтервали кожного дня (початок, кінець, робоча зона/лінія, кількість годин).

2. **Підтвердження годин:**
   - Кнопка **«✅ Підтвердити день»**: змінює статус усіх інтервалів дня на `CONFIRMED`.
   - Якщо це був останній непідтверджений день місяця, координатор отримує сповіщення про повну готовність працівника.

3. **Відкриття диспуту / Скарги:**
   - Кнопка **«❌ Не згоден / Диспут»**:
     1. Вибір категорії проблеми (наприклад: *Пропущені години, Невірний час початку, Невірний час закінчення, Інше*).
     2. Введення коментаря або очікуваних годин.
     3. Статус інтервалу/дня переходить у `DISPUTED`.
     4. Координатор отримує миттєвий пуш-сповіщення у Telegram із кнопкою швидкого переходу до вирішення.

4. **Зголошення пропущеного дня (Missing Day):**
   - Можливість заявити про зміну, яка взагалі не була зафіксована у фабричному табелі.

---

## 2. Кабінет координатора та адміністратора

1. **Реєстр скарг (Disputes Hub):**
   - Єдиний список усіх активних диспутів із фільтрами за місяцем, працівником, лінією та категорією.
   - Можливість в один клік ухвалити рішення:
     - **Прийняти (Resolve):** виправити інтервал або додати новий, статус переходить у `CONFIRMED`.
     - **Відхилити (Reject):** із зазначенням причини працівнику.

2. **Моніторинг підтверджень (% завершення):**
   - Відсоток працівників, які повністю закрили підтвердження за поточний/минулий місяць.
   - Список "боржників" (хто ще не переглянув зміни).

3. **Автоматичні та ручні нагадування:**
   - Щоденні cron-нагадування працівникам із непідтвердженими змінами.
   - Кнопка примусового масового пушу від координатора.
