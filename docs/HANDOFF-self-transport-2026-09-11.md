## Що змінилось

| Шар | Було | Стало |
|---|---|---|
| БД | `workers.self_transport` + `self_transport_since` | таблиця `worker_self_transport` (`worker_id`, `factory_id`, `since`, `until` NULL = досі); легасі-колонки лишаються, **код їх не читає і не пише** |
| Резолвер | розкидано по 13 місцях (`ne(workersTable.selfTransport,true)`) | `services/selfTransport.ts`: `isSelfOn(map, workerId, factoryId, date)`, `selfPredicateForWeek(weekId)`, `hasSelfInRange`, мутації `setSelfTransport` / `moveSelfTransportSince` |
| Генерація знять (`POST /transport/deductions/generate`) | пара self весь місяць → лише посадки | пара **без** self-днів у місяці → з годин сводної (як досі); пара **зі** self-днями → поденно по записах затверджених тижнів: self-день = лише з `picked_up_by`, день «возить фірма» = кожна не-absent явка; скасовані клітинки/draft — ні |
| Перед-звірка перенесення (`POST /svodni/apply-transport-deductions`) | звіряла всіх авто | пропускає пари зі self-днями в місяці |
| Водійські поверхні | фільтр по прапорцю профілю | по даті запису графіку: список посадки й коригування в боті, auto-absent, `GET /driver-board` (headcount/selfCount), `pickupGaps`, пресмінне водієві (`scheduler.ts`), графік головному водію (`notify.ts` 🚶), значок 🚗 у веб-графіку, дашборд «прогалини водіїв» |
| Веб | один селект + дата в профілі | профіль → «Транспорт»: рядок на кожну фабрику (основна + історія + з інтервалами): перемикач «Возить фірма / Доїжджає сам» + дата «з»; «+ інша фабрика». Модалка працівника: чекбокс = інтервал на **обрану** фабрику |
| API | — | `GET /workers/:id/self-transport`, `PUT … {factoryId, self, since?}` (типово сьогодні), `PATCH/DELETE …/:rowId`; профіль віддає `selfTransportRows` + сумісні `selfTransport/selfTransportSince` (зріз по основній фабриці на сьогодні); `GET /transport/deductions` — `selfTransport` = є self-дні пари в місяці |

Семантика `setSelfTransport(w, f, self, since)`: увімкнути = відкрити інтервал з дати (чинний
відкритий — лишається); вимкнути = закрити чинний датою (якщо дата ≤ його початку — інтервал
зноситься); інтервали, що починаються з дати або пізніше, зносяться (ручне перемикання
переписує майбутнє).

## Прод

- Міграції: `2026-09-11-worker-self-transport.sql` (таблиця + сід: чинні прапорці → інтервал на
  основну фабрику; `self_transport_since` NULL → `2000-01-01`) і чужа з того ж деплою
  `2026-09-11-termination-factory.sql` (коміт `ae9a7cd`).
- **Не перенесені сідом:** люди з прапорцем «вимкнено» і датою (на проді 2: Sarokin Ilya з 17.08,
  Sahan Serhii з 10.08) — початок їхнього self-періоду невідомий; серпень у них рахується з годин.
  Якщо треба — додати інтервал руками в профілі (дата «з» → «до»).

  мають серпневі години на іншій платній фабриці (Kopetskyi «- A» LST 93,5h, Kydyraliyev ANDROS 160h,
  Hnatiuk ANDROS 136h, Levenets «- D» ANDROS 88h, Sidliar «- A» ANDROS 88h, Stsibailo BIMIZ 40h,
  Ndlovu ALMIZ 24h, Fedun/Khrystyn/Leibiuk BIMIZ 16h, Pshenychnyi «- D»/Skabara BIMIZ 8h) — там тепер
  «возить фірма», і повторне «Розрахувати» за серпень нарахує їм зняття з годин. Рішення за Yuriy:
  або дописати їм інтервали на ці фабрики (профіль → «+ інша фабрика», або одноразовий SQL з тими ж

  отримає дні до 20.08 за явками + посадки після; далі «Перенести до сводної».
