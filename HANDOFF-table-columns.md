# HANDOFF: порядок і видимість колонок в Обліку годин та Сводній (11.08.2026)

Разова записка сесії. Канонічне — рядок про `web-prefs` у `PROJECT_MAP.md` (оновлений цим же комітом).

## Що зроблено

Вимога власника: переставляти стовпчики в Обліку годин і Сводній drag-ом, без жодного впливу на підрахунки; плюс ховати/показувати колонки в Обліку годин (у Сводній ховання вже було).

- **Механізм** — наявний `admins.web_prefs` (`useOrderPref`/`orderBy`/`useDragOrder` з `web/src/lib/prefs.ts`, ті самі, що тягають вкладки міст/фабрик). API/БД не змінювались.
- **Сводна** (`web/src/pages/Svodni.tsx`): drag за заголовок (`Th` отримав `dragProps`); порядок per-місто — `order.svodni.cols.{місто}`, бурштиновий sensitive-блок лишається в кінці, всередині себе переставляється (`order.svodni.colsSens.{місто}`). Персональний порядок накладається ПОВЕРХ дефолту з `colOrder` Google-вкладки. «Працівник» і «Замітки» фіксовані.
- **Облік годин** (`web/src/pages/Hours.tsx`): головна таблиця рефакторнута з ручної верстки в колонко-орієнтований рендер — каталог `HOURS_COLS` (модульний), опис `colDefs` (th/td/foot на колонку) всередині рендера групи. Drag — глобальний ключ `order.hours.cols`; блок «1/2/3 зм» (`shiftBlock`) — одна логічна колонка. Ховання: «×» на заголовку + кнопка «Колонки» з чипсами під вкладками фабрик, ключ `hidden.hours.cols`. Owner-колонки (rate/net/reportNet) фільтруються з каталогу для не-owner (`OWNER_COL_KEYS`).
- Підпис «Разом по фабриці» переїхав із colSpan у клітинку колонки «Працівник» (colSpan несумісний із довільним порядком).
- i18n: один новий рядок «Розбивка по змінах» → "Per-shift breakdown"; решта підписів уже була в словнику.

## Гарантія «не впливає на підрахунки»

Зміни суто рендерні: суми/«Разом»/звірки рахуються з полів даних, редагування клітинок іде по ключу поля, Excel-експорти формує сервер зі своїм каталожним порядком (`HOURS_XLSX_COLS`, `XLS_COLS`).

## Нюанси для наступних сесій

1. `useDragOrder` зберігає повний ВИДИМИЙ список на drop: колонка, схована під час drag-у, після повернення потрапить у кінець порядку (та сама поведінка, що у вкладок/сводної) — свідомий компроміс.
2. У Сводній ховання колонок як і було — localStorage per місяць+місто+фабрика (`svodni.hiddenCols.*`); у Обліку годин видимість глобальна і їде через web_prefs. Не «вирівнювати» без запиту власника.
3. Нова колонка в Hours = запис у `HOURS_COLS` + гілка в `colDefs` (th/td/foot); порядок/видимість підхопляться самі.
