# Фінансовий огляд місяця

Розбір місяця M за даними системи. Джерела — ендпойнти фінблоку (усі owner-only) або прямі запити до БД через скіл `scratch-db` (read-only). Формат подачі — за преференціями власника: інкрементальні перевірені кроки, скрізь дрил-дауни, питати лише невідоме.

## Що входить у огляд

1. **P&L** (`GET /pnl?month&segment`): дохід **нетто** (KSeF sale за акруалом M−1, матч клієнта по NIP → `factories.client_nip`/`pnl_label`); собівартість = **повна ЗП** (брутто + податки + аванси + хостел); маржа = нетто − собівартість. Сегменти `main` і `cleaning` — **окремо, ніколи не сумувати мовчки**. Кілька фабрик одного клієнта (Agram ×2, Eurocash ×3, InPost ×2) діляють NIP/label — розбивка «по клієнту», не «по фабриці».
2. **Cashflow** (`GET /cashflow`, дрил-даун `GET /cashflow/entries`): банк + готівка по категоріях, рівняння звірки має сходитись.
3. **Баланс на кінець M** (`GET /balance`): гроші + належності (`obligations`, as-of `arisen_date`/`settled_at`) + неоплачені фактури.
4. **Зарплати** (`GET /payroll?month`): по регіонах/фірмах; виплата M живе в M+1 (банк) — не плутати місяць нарахування з місяцем платежу.
5. **Банк** (`GET /bank/summary|breakdown`): приходи/витрати/стан по фірмах; кредитний рахунок поза операційною касою.
6. **Дебіторка:** неоплачені sale-фактури KSeF (оплата = точний номер фактури в назві вхідного переказу — ніколи по сумі).

## Правила подачі

- Кожна цифра має джерело; порівняння з минулим місяцем — теж за акруалом, а mtd поточного — по явках (рапортів ще нема).
- Розбіжності між джерелами не згладжувати — показати і назвати причину (або перейти в режим `fin-check`).
- Таблиці компактні: показник / M−1 / M / Δ; дрил-даун за запитом (по клієнту, по категорії, по фірмі).
- Візуалізація (за запитом) — сторінки панелі вже мають графіки; разові чарти — через скіл dataviz.
- Фінансові цифри — owner-only: не вставляти їх у код/доки/комміти; звіт — тільки в чат користувачу.

## Швидкі перевірки притомності звіту

- Σ сегментних P&L ≠ обов'язково загальний банк-рух (акруал ≠ кеш) — якщо користувач питає «чому не збігається з банком», пояснити різницю нарахування/оплата, не «підганяти».
- Місяць вважається закритим, коли: сводні залочені (`svodni_locks`, без `staleLocks`), KSeF синкнутий, витяги M+1 імпортовані (виплати ЗП). До того — маркувати цифри як попередні.
