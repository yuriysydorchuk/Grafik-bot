# HANDOFF: темна тема веб-панелі (24.07.2026)

Одноразова записка сесії. Довговічне правило вже перенесено в `CLAUDE.md` (розділ «Правила розробки», пункт «Темна тема веб-панелі»).

## Що зроблено

Повна темна тема адмінпанелі **без правок верстки сторінок** — через перевизначення CSS-змінних палітри:

- **`artifacts/web/src/index.css`** — ядро: `@custom-variant dark` + блок `.dark` з повною темною палітрою.
  - Нейтральні (white/slate/gray) — ручний графітовий рамп (сторінка `#10141e`, картки `#1b2130`), брендовий червоний відкалібрований окремо.
  - 16 акцентних відтінків — згенеровані дзеркалюванням дефолтної шкали Tailwind (50↔950, 100↔900, 200↔800, 300↔700, 900→100; 400/500 без змін, 600→500) з приглушенням фонів: `*-50` (панелі) хрома ×0.55, `*-100` (бейджі) ×0.8, `*-200` (рамки) ×0.7. Бейджі `bg-*-100 text-*-700` автоматично стають «темний фон + пастельний текст».
  - Unlayered дарк-фікси: `text-white` лишається білим, скрим модалок `bg-slate-900/40` лишається темним, **суцільні кнопки** (`bg-red-600`, `bg-rose-600`, `bg-emerald-600`, `bg-sky-600` + їх hover-700) тримають насичені світлотемні кольори (інакше були пастельно-вимиті), градієнт аватарки `to-red-700`.
  - Новий токен `--color-page` → утиліта `bg-page` (фон сторінки + липкі фільтр-бари в Hours/Workers/Schedule замість хардкод-hex).
- **`artifacts/web/src/lib/theme.ts`** (новий) — стор теми: light/dark/system, localStorage `theme`, клас `dark` на `<html>`, `useTheme()` (useSyncExternalStore), `useChartTheme()` для recharts (сітка/осі/тултіпи — recharts не вміє CSS-var у пропсах). У Telegram Mini App «system» бере `Telegram.WebApp.colorScheme` (localStorage там не живе).
- **`artifacts/web/index.html`** — інлайн-скрипт до першого рендера (без спалаху білого).
- **`components/Layout.tsx`** — кнопка-перемикач (цикл світла → темна → системна) в обох шапках; **`main.tsx`** — sonner Toaster слідує темі.
- **`pages/Dashboard.tsx` + `pages/Finance.tsx`** — графіки через `useChartTheme()`.
- **Логотип:** `public/logo-dark.png` (згенерований з `logo.png`: чорний підпис → світлий, червоний ES без змін); компонент `Logo` у `components/ui.tsx` свапає за темою; використаний у Layout (×2) і Login.
- **i18n:** «Тема: світла/темна/як у системі» — EN + RU.

Світла тема **не змінена** (усі оверрайди під `.dark`; перевірено скриншотами).

## Перевірено

`pnpm run typecheck` по всіх пакетах чистий; веб зібраний. Скриншоти через headless Chrome (playwright, channel=chrome): логін, харнес із сайдбаром/картками/таблицею/бейджами всіх 19 кольорів/формами/модалкою — обидві теми.

**Не перевірено вживу:** залогінені сторінки з реальними даними (Графіки-сітка, Сводні, Витяги, Рекрутинг-канбан). Якщо десь у дарку негарно — правити точково: палітру в `.dark` у `index.css` або unlayered фікс поруч з наявними.

## Гочі для майбутніх правок

- Нова верстка має використовувати стандартні шкали Tailwind (`bg-white`, `slate-*`, `bg-*-100 text-*-700`) — тоді дарк працює сам. Hex-хардкод у класах/інлайн-стилях = біла пляма в дарку.
- Кольори графіків — лише з `useChartTheme()`.
- При бампі Tailwind з оновленням палітри — перегенерувати акцентний блок тим самим дзеркалом (правило в CLAUDE.md).
- У сесії лишилися **чужі незакомічені правки** `bot/i18n.ts` + `bot/index.ts` і записка `HANDOFF-hours-workers-sticky.md` (інша сесія) — до цієї роботи не належать, не закомічені.
